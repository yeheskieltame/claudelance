## ACTION REQUIRED - deployed contracts (v3 UUPS via Safe; v2 immutable)

Source edits do nothing on-chain. v3 needs a reviewed impl + Safe `upgradeToAndCall`;
v2 (`0x1362d8...E423`) is immutable - these are notes for any successor only.

1. **HIGH (design) - pause does not stop fund outflow (v3).** `withdrawEarnings`,
   `pickWinner`, `settleStake`, `cancelExpired` all run while paused; only
   posting/claiming/attesting carry `whenNotPaused`. This is partly deliberate
   (users should always be able to exit), so it is a **decision**, not a clear bug:
   adding `whenNotPaused` to `pickWinner` / `settleStake` / `cancelExpired` (which
   only credit internal balances or refund the poster) gives the owner a real brake
   without freezing user `withdrawEarnings`. Weigh censorship vs. circuit-breaker.
2. **LOW (gas) - `pickWinner` re-reads `totalProtocolRevenue` from storage** right
   after writing it (the `cumulative` for the event). Use the in-memory value.
3. **over-eng - `TypeConfig.minReviewers`** is stored and configurable but never read
   by any contract logic. Drop it from the next clean deployment.
4. **deadcode - `BountyLib.NoSubmission`** is declared/imported but never reverted.
5. **LOW - `attestCI` only works while `Open`** so CI can't be corrected after
   `pickWinner` (one-shot race for the relayer). Acceptable; documented here.
6. **v2 is NOT dead code** - `ClaudelanceCore.sol` is live and independent on
   mainnet. Do not delete. (Its `reputationRegistry` immutable and `Expired` enum
   are unused, and `MockCUSD` is superseded by `MockERC20`, but v2 is immutable.)

## Remaining off-chain tail (low priority, safe to do anytime)

Highest value first:

- `services/reset.ts` (856 lines) - bespoke two-phase token + idempotency-envelope
  + double-hash protocol for a fully reversible soft-delete. Strong simplify target (~120 lines).
- `middleware/auth.ts` issues a blocking `UPDATE api_keys` on **every** request -
  fire-and-forget or throttle to once per ~60s.
- `services/webhooks.ts` / `coordination.ts` / `reset.ts` - sequential awaits and
  per-item loops that should be `Promise.all` / one set-based query.
- `automations.ts` create_task computes `max()+1` then inserts non-atomically (race).
- SDK `packages/sdk/src/client.ts`: dead v2 `getBountyCount`/`getEarnings` paths on a
  v3 target; `waitForBounty`/`waitForSubmission` duplicate poll loops;
  `ERC721_BALANCE_OF_ABI` misnamed (reads ERC20); `celoGas` 2x cap is thin under spikes.
- Web: duplicated helpers across components (`toIso`, `VERDICT_LABEL`, members->name
  map, Escape/Tab focus-trap); `bounties-table` token filter paginates up to 2500
  client-side; `post-bounty-page.tsx` (1523 lines) duplicate per-type hint maps.
- `~9 scripts` hand-roll the same `--flag` arg parser.
